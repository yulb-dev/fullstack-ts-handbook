# Tailwind CSS 新手教程：从 0 到 1 构建可维护的 utility-first 样式体系

> 基于 **Tailwind CSS v4.3**（当前官方最新主版本）编写。Tailwind v4 与 v3 在配置方式上有重大差异（CSS-first 配置取代 JS 配置文件），本教程全程以 v4 为准，并在第 10 章专门讲解新旧版本差异。
> **重要**：学习任何框架文档时，先确认你项目锁定的主版本，然后只看对应版本的文档（官方文档站左上角可以切换版本）。网上大量教程仍是 v3 甚至 v2 的写法，照抄会踩坑。

## 这份教程适合谁

- 会 HTML / CSS / JavaScript 基础，接触过 React、Vue 或原生前端项目的前端新手；
- 想系统学习 Tailwind CSS，而不是只会复制粘贴几个类名；
- 目标是：**形成可维护的 utility-first 样式方式，并能在响应式、主题与组件状态下保持一致**。

## 学完之后你将能够

1. 用 utility-first 思想把布局、尺寸、排版、颜色、边框、阴影、间距映射为组合类名；
2. 熟练使用响应式断点变体（`sm:`、`md:`…）和状态变体（`hover:`、`focus:`、`active:`、`disabled:`、`group-*`、`peer-*`）；
3. 用 CSS-first 的 `@theme` 定义设计 token 与语义颜色，支持深色模式，杜绝散落的硬编码色值；
4. 用 flex/grid 处理布局，理解溢出、定位、z-index、容器宽度与移动端优先的布局策略；
5. 设计合理的组件 className API，会用条件组合类名，划分样式职责；
6. 明白为什么不能动态拼接类名，会用明确映射和 `@source inline()`（safelist）解决问题；
7. 理解 utility 框架不能替代的东西：CSS 语义、可访问性、层叠模型。

## 学习路线建议

```
第 1 章（基础 CSS 自检）
   └─> 第 2 章（搭环境，跑起来）
         └─> 第 3 章（建立 utility-first 心智模型）★ 最重要的一章
               └─> 第 4 章（常用 utility，边查边练）
                     ├─> 第 5 章（响应式）
                     ├─> 第 6 章（状态变体）
                     └─> 第 7 章（深色模式）
                           └─> 第 8 章（主题令牌）★ 可维护性的关键
                                 └─> 第 9 章（组件化与工程实践）
                                       └─> 第 10 章（版本差异 + 综合实战 + 验收）
```

- **每章都包含可运行的代码示例和练习**，强烈建议一边读一边在编辑器里敲，不要只用眼睛看；
- 第 4 章偏"字典"性质，第一遍通读建立印象即可，之后当查询手册用；
- 第 3、8、9 章是"可维护"三个字的灵魂，值得反复读。

## 贯穿全书的实战项目

教程后半部分会围绕一个迷你项目「**TaskBoard 任务看板页**」展开：一个响应式、支持深色模式、组件化的任务卡片列表页面。它会在第 5、6、7、9、10 章逐步演进，最终成为你检验学习成果的完整作品。
