# 第 10 章 · 综合实战：把九章串成一个完整应用

> 本章目标：**把前面九章的能力整合成一个完整、可运行、结构清晰的 Concert Hub 应用**，并回顾「每个核心概念落在代码的哪一处」。
> 对应验收项：全部
> 预计用时：90 分钟

前九章我们逐点掌握了各个能力。这一章不引入新概念，而是**把它们组织成一套「清晰的路由系统」**——这正是本教程开头承诺的目标。

完整可运行代码见仓库 [`example/`](../example) 目录。本章讲解**架构设计**与**关键文件**，并在末尾给出运行/部署方式与总复盘。

## 10.1 最终架构总览

我们要做的 Concert Hub 具备：

- 全局布局（header/nav/footer）+ 全局 pending 进度条 → 第 2、5 章
- 首页（列表，loader 加载）→ 第 3 章
- 演唱会区（区块布局 + 城市列表侧边栏 + 列表 + 详情）→ 第 2、3 章
- 城市列表页：搜索 + 排序 + 分页，全部由 URL 驱动 → 第 3、7 章
- 新建 / 编辑：表单提交 + 服务端校验错误映射 + 成功 redirect → 第 4 章
- 收藏按钮：fetcher 局部提交 + 乐观更新，不改 URL → 第 5 章
- 管理报表：受保护（未登录 redirect、无权 403）+ route lazy 代码拆分 → 第 6、8 章
- 404 / 403 / 崩溃三类错误分别处理 → 第 6 章
- 单元测试覆盖 loader/action/组件 → 第 9 章

**目录结构：**

```
src/
├─ main.tsx                      # 入口：渲染 RouterProvider
├─ router.tsx                    # 路由表（唯一的路由配置中心）
├─ api.ts                        # mock 数据层（带延迟 + 支持取消）
├─ auth.ts                       # 极简「登录态」模拟
├─ styles.css
└─ routes/
   ├─ root.tsx                   # 全局布局 + 全局进度条
   ├─ root-error.tsx             # 根错误边界（404/403/500 分发）
   ├─ not-found.tsx              # URL 未匹配的兜底页
   ├─ home.tsx                   # 首页
   ├─ about.tsx
   ├─ login.tsx
   ├─ concerts/
   │  ├─ layout.tsx              # 区块布局（侧边栏城市 + Outlet）
   │  ├─ city.tsx                # 列表页（搜索/排序/分页，URL 驱动）
   │  ├─ detail.tsx              # 详情页（loader 404 + fetcher 收藏）
   │  ├─ new.tsx                 # 新建（校验错误映射 + redirect）
   │  └─ edit.tsx                # 编辑
   └─ admin/
      └─ report.tsx              # 受保护 + lazy 拆分 + 重依赖
```

💡 **设计原则回顾**：
- **`router.tsx` 是唯一的路由真相来源**：页面层级、URL、每个路由的 loader/action/边界/lazy 全在这里一览无余。
- **数据逻辑在 loader/action，UI 逻辑在组件，业务校验在纯函数**：三层分离，各自可测（第 9 章）。
- **状态归属清晰**：可分享的状态在 URL，一次性上下文在 history state，服务端数据在 loaderData。

## 10.2 路由表：整个系统的「地图」

这是全应用最关键的一个文件。请对照前面每一章，看每个字段是怎么来的。

```tsx filename=src/router.tsx
import { createBrowserRouter, redirect } from "react-router";

import Root from "./routes/root";
import RootErrorBoundary from "./routes/root-error";
import Home, { loader as homeLoader } from "./routes/home";
import About from "./routes/about";
import Login, { action as loginAction } from "./routes/login";
import NotFound from "./routes/not-found";

import ConcertsLayout, { loader as concertsLayoutLoader } from "./routes/concerts/layout";
import ConcertsCity, { loader as cityLoader } from "./routes/concerts/city";
import ConcertDetail, { loader as detailLoader, action as favoriteAction } from "./routes/concerts/detail";
import NewConcert, { action as newAction } from "./routes/concerts/new";
import EditConcert, { loader as editLoader, action as editAction } from "./routes/concerts/edit";

import { getSession } from "./auth";

export const router = createBrowserRouter([
  {
    path: "/",
    Component: Root,
    ErrorBoundary: RootErrorBoundary,        // 第 6 章：根兜底错误边界
    children: [
      { index: true, Component: Home, loader: homeLoader },   // 第 2 章 index + 第 3 章 loader
      { path: "about", Component: About },
      { path: "login", Component: Login, action: loginAction },

      {
        path: "concerts",
        Component: ConcertsLayout,           // 第 2 章：区块布局
        loader: concertsLayoutLoader,        // 侧边栏城市列表
        children: [
          { index: true, Component: ConcertsCity, loader: cityLoader }, // /concerts 默认页
          { path: ":city", Component: ConcertsCity, loader: cityLoader }, // 第 3、7 章：URL 驱动列表
          { path: "new", Component: NewConcert, action: newAction },       // 第 4 章：新建
          {
            path: ":city/:concertId",
            Component: ConcertDetail,
            loader: detailLoader,            // 第 3、6 章：找不到 throw 404
            action: favoriteAction,          // 第 5 章：fetcher 收藏
          },
          {
            path: ":city/:concertId/edit",
            Component: EditConcert,
            loader: editLoader,
            action: editAction,
          },
        ],
      },

      {
        // 第 6 章权限 + 第 8 章 lazy：受保护且重型的后台报表
        path: "admin/report",
        lazy: async () => {
          const mod = await import("./routes/admin/report");
          return { Component: mod.default, loader: mod.loader };
        },
      },

      { path: "*", Component: NotFound },   // 第 2、6 章：URL 未匹配兜底
    ],
  },
]);
```

对照验收：
- **页面层级** = `children` 嵌套 + `<Outlet/>`（第 2 章）
- **URL** = `path` / `index` / `:param` / `*`（第 2 章）+ 查询参数（第 7 章）
- **加载数据** = 各路由 `loader`（第 3 章）
- **提交数据** = 各路由 `action`（第 4、5 章）
- **导航状态** = 根布局里的 `useNavigation`/`useFetchers`（第 5 章）
- **错误处理** = `ErrorBoundary` + `throw data` + `path:"*"`（第 6 章）
- **代码拆分** = admin 路由的 `lazy`（第 8 章）

## 10.3 数据层与「登录态」模拟

```ts filename=src/api.ts
const delay = (ms: number, signal?: AbortSignal) =>
  new Promise<void>((resolve, reject) => {
    const t = setTimeout(resolve, ms);
    signal?.addEventListener(
      "abort",
      () => { clearTimeout(t); reject(new DOMException("Aborted", "AbortError")); },
      { once: true }
    );
  });

export type Concert = { id: string; city: string; title: string; date: string; favorite?: boolean };

let concerts: Concert[] = [
  { id: "1", city: "salt-lake-city", title: "The Folklore Sessions", date: "2026-11-02" },
  { id: "2", city: "salt-lake-city", title: "Neon Desert Live", date: "2026-11-18" },
  { id: "3", city: "chicago", title: "Windy City Rockfest", date: "2026-12-05" },
  { id: "4", city: "chicago", title: "Jazz by the Lake", date: "2026-12-20" },
];

export const CITIES = ["salt-lake-city", "chicago"] as const;

export async function listConcerts(opts: { signal?: AbortSignal } = {}) { await delay(300, opts.signal); return concerts; }
export async function getConcert(id: string, opts: { signal?: AbortSignal } = {}) { await delay(400, opts.signal); return concerts.find((c) => c.id === id); }
export async function getConcertsByCity(city: string, opts: { signal?: AbortSignal } = {}) { await delay(300, opts.signal); return concerts.filter((c) => c.city === city); }

export async function createConcert(input: Partial<Concert>) {
  await delay(500);
  const c: Concert = { id: String(Date.now()), city: input.city ?? "chicago", title: input.title ?? "Untitled", date: input.date ?? new Date().toISOString().slice(0, 10) };
  concerts.push(c); return c;
}
export async function updateConcert(id: string, patch: Partial<Concert>) {
  await delay(500);
  concerts = concerts.map((c) => (c.id === id ? { ...c, ...patch } : c));
  return concerts.find((c) => c.id === id)!;
}
```

```ts filename=src/auth.ts
// 极简登录态：真实项目请走服务端 session / token
const KEY = "ch_user";
export type User = { name: string; role: "user" | "admin" };
export function getSession(): User | null {
  const raw = localStorage.getItem(KEY);
  return raw ? (JSON.parse(raw) as User) : null;
}
export function setSession(u: User | null) {
  if (u) localStorage.setItem(KEY, JSON.stringify(u));
  else localStorage.removeItem(KEY);
}
```

## 10.4 关键路由文件（精选讲解）

完整代码在 [`example/src/routes/`](../example/src/routes)。这里挑最能体现「概念整合」的三处。

### (A) 根布局：全局 pending + Outlet（第 2、5 章）

```tsx filename=src/routes/root.tsx
import { Outlet, NavLink, useNavigation, useFetchers } from "react-router";

export default function Root() {
  const navigation = useNavigation();
  const fetchers = useFetchers();
  const busy = Boolean(navigation.location) || fetchers.some((f) => f.state !== "idle");

  return (
    <div>
      <div className="progress" data-busy={busy} />
      <header>
        <nav>
          <NavLink to="/" end>首页</NavLink>
          <NavLink to="/concerts">演唱会</NavLink>
          <NavLink to="/admin/report">后台报表</NavLink>
          <NavLink to="/about">关于</NavLink>
        </nav>
      </header>
      <Outlet />
      <footer>© 2026 Concert Hub</footer>
    </div>
  );
}
```

### (B) 详情页：loader 404 + fetcher 乐观收藏（第 3、5、6 章）

```tsx filename=src/routes/concerts/detail.tsx
import { data, useLoaderData, useFetcher, Link } from "react-router";
import { getConcert, updateConcert } from "../../api";
import type { Concert } from "../../api";

export async function loader({ params, request }) {
  const concert = await getConcert(params.concertId, { signal: request.signal });
  if (!concert) throw data("找不到这场演唱会", { status: 404 }); // 第 6 章
  return { concert };
}

// 收藏 = 局部提交，不改 URL（第 5 章 fetcher 会调它）
export async function action({ request, params }) {
  const fd = await request.formData();
  const favorite = fd.get("favorite") === "true";
  await updateConcert(params.concertId, { favorite });
  return { ok: true, favorite };
}

export default function ConcertDetail() {
  const { concert } = useLoaderData() as { concert: Concert };
  const fetcher = useFetcher<typeof action>();

  // 乐观更新：提交中先用 fetcher.formData 猜出下一状态
  const favorite = fetcher.formData
    ? fetcher.formData.get("favorite") === "true"
    : !!concert.favorite;

  return (
    <article>
      <h1>{concert.title}</h1>
      <p>{concert.city} · {concert.date}</p>

      <fetcher.Form method="post">
        <input type="hidden" name="favorite" value={favorite ? "false" : "true"} />
        <button type="submit" disabled={fetcher.state !== "idle"}>
          {favorite ? "★ 已收藏" : "☆ 收藏"}
        </button>
      </fetcher.Form>

      <p><Link to={`/concerts/${concert.city}/${concert.id}/edit`}>编辑</Link></p>
    </article>
  );
}
```

### (C) 受保护的后台报表：权限 + lazy（第 6、8 章）

```tsx filename=src/routes/admin/report.tsx
import { data, redirect, useLoaderData } from "react-router";
import { getSession } from "../../auth";

export async function loader({ request }) {
  const user = getSession();
  if (!user) return redirect(`/login?from=${new URL(request.url).pathname}`); // 未登录改道
  if (user.role !== "admin") throw data("你没有权限访问后台报表", { status: 403 }); // 无权 403
  return { user, revenue: 128_000 };
}

export default function AdminReport() {
  const { user, revenue } = useLoaderData();
  return (
    <main>
      <h1>后台报表</h1>
      <p>你好，{user.name}（管理员）。本月票房收入：¥{revenue.toLocaleString()}</p>
    </main>
  );
}
```

> 这个文件在 `router.tsx` 里通过 `lazy` 动态导入，所以它（以及它引入的任何重依赖）只在用户真正访问 `/admin/report` 时才被下载（第 8 章）。

## 10.5 运行与部署

### 本地运行示例工程

```bash
cd example
npm install
npm run dev      # 打开 Vite 提示的地址（默认 http://localhost:5173）
npm run build    # 产物在 dist/，可看到按路由拆分的多个 chunk
npm run test:run # 运行单元测试（第 9 章）
```

体验清单（亲手验证每章能力）：
1. 首页 → 演唱会，观察顶部进度条与 NavLink 的 active/pending（第 5、7 章）。
2. 进入某城市，试搜索/排序/翻页，**复制 URL 到新标签**打开，结果一致（第 7 章）。
3. 点详情页「收藏」，按钮立刻变化但 **URL 不变**（第 5 章 fetcher 乐观更新）。
4. 新建演唱会：先提交空表单看**字段错误 + 输入不丢**，再填对看**自动跳详情**（第 4 章）。
5. 手动访问 `/concerts/chicago/999` 看**友好 404**；访问 `/some-random` 看**兜底 404**（第 6 章）。
6. 未登录访问 `/admin/report` → 跳登录；以非管理员登录再访问 → 看 **403**（第 6 章）。
7. `npm run build` 看 admin 报表被拆成**独立 chunk**，首次访问才加载（第 8 章）。

### 部署到静态服务器：SPA fallback（务必配置）

Data Mode 的 `createBrowserRouter` 用浏览器 History API，URL 像 `/concerts/chicago`。**服务器必须把所有未命中静态文件的路径回退到 `index.html`**，否则用户直接访问或刷新深层 URL 会得到 404。

- **Nginx**：`try_files $uri $uri/ /index.html;`
- **Vercel**：加 `rewrites`，把 `/(.*)` 重写到 `/index.html`。
- **Netlify**：`/* /index.html 200`（`_redirects` 文件）。
- **纯静态 GitHub Pages**：需注意子路径要设 `createBrowserRouter(routes, { basename: "/repo-name" })`。

> ⚠️ Vite 的 **dev 服务器已自动处理** fallback，所以本地不会遇到；问题只在生产部署时出现，别忘了配置。

## 10.7 下一步学什么

- **升级到 Framework Mode**：当你需要 SSR/SSG、类型安全的 `href` 与 loaderData、自动代码拆分时，迁移到 `@react-router/dev`。概念（loader/action/fetcher/边界）**完全一致**，主要变化是「文件即路由」与类型生成。
- **`<Await>` + 流式数据**：对「慢数据」先渲染外壳、数据到了再补（`useAsyncValue` / `useAsyncError`）。
- **`handle` + `useMatches`**：做面包屑、按路由设置 body class、权限元数据等。
- **`middleware`（v8 新）**：把日志、鉴权等横切逻辑收敛到路由中间件。
- **View Transitions**：用 React 的 `<ViewTransition>` 做路由切换动画。
- **`useBlocker` / `usePrompt`**：拦截「有未保存修改时离开页面」。
